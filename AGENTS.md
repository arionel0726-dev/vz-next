# Vizaje Nica — правила проекта

## Проект

Новый интернет-магазин косметики Vizaje Nica.

## Стек

- Laravel
- PHP
- MySQL
- Vue 3
- TypeScript
- Inertia.js
- Vite
- Tailwind CSS
- Redis
- Pest
- Playwright

## Правила

- Не изменять legacy-проект vizaje-nica.
- Новый код размещать только в vizaje-nica-next.
- Не использовать микросервисы без необходимости.
- Бизнес-логику не помещать во Vue-компоненты.
- Цены, скидки, остатки и правила рулетки считать только на сервере.
- Все изменения базы делать через Laravel migrations.
- Не удалять старые таблицы без отдельного подтверждения.
- Для каждого крупного модуля добавлять тесты.
- Использовать единый компонент карточки товара.
- Поддерживать русский и румынский языки.
- Проверять мобильную и desktop-версию.
